以下是针对您列出的图像处理技术的系统解释，涵盖原理、典型算法和应用场景：

一、图像滤波（Image Filtering）

目的：抑制噪声、平滑图像或增强特定特征。  
原理：通过卷积核（滤波器）在图像上滑动，计算邻域像素的加权和。  
典型算法：  
• 均值滤波：邻域像素平均值，消除高斯噪声但模糊边缘。  

• 高斯滤波：加权平均（权重服从高斯分布），保留边缘优于均值滤波。  

• 中值滤波：取邻域像素中值，有效去除椒盐噪声。  

• 双边滤波：结合空间距离和像素值相似性，保边去噪。  

应用：预处理降噪、皮肤美化（美颜算法）。

二、轮廓提取（Contour Extraction）

目的：提取物体外边界或内部结构的连续曲线。  
原理：基于边缘检测结果，连接相邻边缘点形成闭合/开放轮廓。  
典型算法：  
• Canny边缘检测 + 轮廓追踪：  

  1. Canny检测边缘点；  
  2. 通过边界跟踪算法（如Moore-Neighbor）连接成轮廓。  
• 二值图像轮廓提取：  

  • Suzuki85算法（OpenCV中findContours）：通过层级关系提取轮廓。  

应用：物体形状分析、OCR字符轮廓提取。

三、边缘检测（Edge Detection）

目的：定位图像中灰度/颜色突变的位置（物体边界）。  
原理：利用梯度算子检测像素值变化率。  
典型算法：  
• 一阶微分算子：  

  • Sobel：计算水平和垂直梯度（核：[-1 0 1; -2 0 2; -1 0 1]）。  

  • Prewitt：类似Sobel，权重更均匀。  

• 二阶微分算子：  

  • Laplacian：直接计算二阶导数（对噪声敏感）。  

• Canny算法（最优边缘检测）：  

  1. 高斯滤波去噪 → 2. 计算梯度 → 3. 非极大值抑制 → 4. 双阈值连接边缘。  
应用：目标识别、三维重建中的特征匹配。

四、形态学处理（Morphological Operations）

目的：改变物体形状、去除噪声或连接断裂区域。  
原理：基于结构元素（如3×3矩形）对二值图像进行逻辑运算。  
基本操作：  
• 腐蚀（Erosion）：消除边界点，缩小物体（去小噪点）。  

• 膨胀（Dilation）：填充空洞，扩大物体（连接断裂）。  

• 开运算：先腐蚀后膨胀（消除小物体）。  

• 闭运算：先膨胀后腐蚀（填充小孔洞）。  

高级操作：  
• 形态学梯度（膨胀–腐蚀）：提取物体边界。  

• 顶帽变换（原图–开运算）：增强亮细节。  

应用：车牌识别中的字符分割、医学图像去噪。

五、图像分割（Image Segmentation）

目的：将图像划分为具有相似属性的区域（如物体、背景）。  
分类与方法：  
1. 基于阈值：  
   • 全局阈值（Otsu算法）：自动选择最佳阈值分离前景/背景。  

   • 自适应阈值：局部计算阈值，解决光照不均问题。  

2. 基于边缘：结合边缘检测结果分割物体（如分水岭算法）。  
3. 基于区域：  
   • 区域生长：从种子点合并相似像素。  

   • 区域分裂合并：递归分割/合并区域。  

4. 深度学习分割：  
   • U-Net（医学影像）：编码器-解码器结构，跳跃连接保留细节。  

   • Mask R-CNN：实例分割（区分同类物体）。  

应用：肿瘤检测、自动驾驶场景解析。

六、图像拼接（Image Stitching）

目的：将多幅重叠图像合成一张全景图。  
流程：  
1. 特征匹配：SIFT/SURF提取关键点，FLANN匹配同名点。  
2. 配准对齐：计算单应性矩阵（Homography），用RANSAC剔除误匹配。  
3. 图像融合：多频段融合（Laplacian金字塔）消除接缝。  
应用：全景照片、卫星地图合成。

七、图像融合（Image Fusion）

目的：合并多幅图像信息，提升整体信息量或视觉效果。  
方法：  
• 像素级融合：加权平均（简单但易重影）。  

• 多尺度融合：  

  • 小波变换：分解图像到不同频段，分别融合后重建。  

  • 拉普拉斯金字塔：保留高频细节和低频轮廓。  

应用：多模态医学成像（CT+MRI）、HDR合成。

八、去噪（Denoising）

目的：去除图像采集/传输中引入的噪声。  
分类：  
• 加性噪声（如高斯噪声）：  

  • 非局部均值（NLM）：利用相似图像块加权平均。  

• 乘性噪声（如散斑噪声）：  

  • 各向异性扩散（Perona-Malik）：沿边缘方向平滑。  

• 脉冲噪声（椒盐噪声）：中值滤波效果最佳。  

深度学习：DnCNN、U-Net等端到端去噪模型。

九、图像增强（Image Enhancement）

目的：改善视觉效果或突出特定特征。  
方法：  
• 对比度增强：  

  • 直方图均衡化：拉伸灰度分布（易过度增强）。  

  • CLAHE：限制局部对比度，避免噪声放大。  

• 锐化：  

  • Unsharp Masking：原图 + 高反差细节（如原图 – 高斯模糊图）。  

• 颜色增强：  

  • 白平衡（灰度世界法）、饱和度调整（HSV空间）。  

十、特征提取（Feature Extraction）

目的：从图像中提取可区分、鲁棒的信息表示。  
类型：  
• 局部特征：  

  • SIFT：尺度不变，128维描述子。  

  • ORB：FAST角点 + BRIEF描述子（效率高）。  

• 全局特征：  

  • HOG（方向梯度直方图）：描述物体轮廓（行人检测）。  

  • 纹理特征：LBP（局部二值模式）、GLCM（灰度共生矩阵）。  

十一、基元拟合（Primitive Fitting）

目的：将离散点集拟合为几何基元（直线、圆、平面等）。  
方法：  
• 最小二乘法：最小化点到模型的平方距离（对离群点敏感）。  

• RANSAC（随机采样一致）：  

  1. 随机采样点估计模型 → 2. 统计内点数量 → 3. 迭代选择最优模型。  
应用：工业检测（圆孔定位）、点云平面分割（三维重建）。

技术对比与关联

技术 输入 输出 依赖技术

应用场景总结

• 工业检测：形态学（缺陷分割）、基元拟合（尺寸测量）。  

• 医疗影像：图像分割（器官划分）、去噪（超声图像）。  

• 自动驾驶：边缘检测（车道线）、图像融合（多传感器）。  

• 安防监控：背景减除（运动检测）、轮廓提取（入侵物体）。  

这些技术常组合使用（如“边缘检测→轮廓提取→基元拟合”实现工业零件测量），需根据任务需求选择合适算法。
